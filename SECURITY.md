# Security Policy

## Supported Versions

Only the latest stable release is actively maintained and patched for security issues. Users are strongly encouraged to upgrade to the newest version whenever possible.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue for security vulnerabilities.**

Instead, report it privately by through GitHub's Private Vulnerability Reporting feature.

Please include the following information in your report:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version(s)
- Any potential impact you believe the vulnerability may cause
- Possible fixes or mitigation suggestions (if known)

### Response Process

- You should receive an acknowledgment within **48–72 hours**.
- After the issue is confirmed, we will work on a fix and keep you updated on progress.
- If the vulnerability is accepted, a patch will be released as soon as possible and the issue will be publicly disclosed after the fix is available.
- If the report is declined (for example, if it is not a security issue), we will explain the reasoning.

We appreciate responsible disclosure and the efforts of security researchers who help keep the project and its users safe.
